# We rebuilt a desktop 3D printer in software

A recognisable desktop printer, rebuilt as a browser-based engineering twin in LabWired.

The demonstration combines parametric CAD, compiled STM32 firmware, four motion axes, endstops, temperature inputs, heater and fan control, an OLED, fault tests, and a routed controller PCB study.

The point is not to make another animation. The same project connects the mechanics, electronics and firmware evidence in one shareable device before physical hardware exists.
