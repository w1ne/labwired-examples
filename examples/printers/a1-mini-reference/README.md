# A1 mini-inspired firmware-controlled printer reference

This promotional reference demonstrates a recognisable desktop 3D-printer workflow in LabWired and KernelCAD:

- parametric machine CAD;
- compiled STM32F411 firmware;
- X, Y, Z and E STEP/DIR motion;
- endstop and temperature input handling;
- heater, fan and driver-control logic;
- OLED states and negative safety tests;
- circuit-to-PCB routing evidence.
