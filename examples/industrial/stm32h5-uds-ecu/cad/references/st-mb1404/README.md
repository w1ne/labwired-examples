# ST MB1404 populated board reference

These files are unchanged primary references from STMicroelectronics for the purchased NUCLEO-H563ZI board. The STEP is the populated MB1404-H563ZI-C01 assembly published in the manufacturing archive. The adjacent provenance file records every archive and included-file SHA-256.

ST retains copyright. The original Open Platform License Agreement notices are preserved in the two readme files. These references are not covered by this repository’s MIT license.

The original H563ZI BOM lists the Morpho CN11/CN12 headers as not fitted. Do not infer installed connectors from an unpopulated footprint. The mount fit and actual installed-board qualification are recorded separately.
